============================================================
 VaultMind per Windows
============================================================

------------------------------------------------------------
OPZIONE A — App vera con icona sul Desktop (consigliata)
------------------------------------------------------------
1. Entra nella cartella  vaultmind-app
2. Doppio clic su  "Installa VaultMind.bat"   (UNA volta sola)
   - crea VaultMind.exe con icona
   - mette un collegamento "VaultMind" sul Desktop
   La build richiede qualche minuto la prima volta.
3. Da qui in poi: doppio clic sull'icona "VaultMind" sul Desktop.
   Si apre direttamente la FINESTRA dell'app (niente terminale).

------------------------------------------------------------
OPZIONE B — Avvio rapido senza creare il .exe
------------------------------------------------------------
Doppio clic su  "Avvia VaultMind.vbs"  (oppure vaultmind-app\run.bat)
Parte il setup in una finestra e poi si apre l'app.

------------------------------------------------------------
OLLAMA (per le risposte intelligenti di "mind")
------------------------------------------------------------
L'assistente in chat si chiama "mind". Per le risposte intelligenti
serve Ollama (gratis, gira in locale). L'avvio con run.bat lo installa
in automatico (via winget). Con il solo .exe, se Ollama manca, l'app
funziona comunque in modalita' base (ricerca locale senza chatbot).
Per installarlo a mano: https://ollama.com/download
poi in un terminale:  ollama pull llama3.2:3b

------------------------------------------------------------
SE WINDOWS BLOCCA IL FILE (.vbs o .exe)
------------------------------------------------------------
SmartScreen puo' avvisare ("Windows ha protetto il PC").
Clicca "Ulteriori informazioni" > "Esegui comunque".

------------------------------------------------------------
NOTE
------------------------------------------------------------
- Il vault cifrato sta in:  %USERPROFILE%\.vaultmind\vault.json
- Le impostazioni in:        %USERPROFILE%\.vaultmind\settings.json
- Per azzerare tutto: elimina vault.json.
- L'app NON e' esposta in rete: ascolta solo su 127.0.0.1.
- WebView2 (motore della finestra) e' gia' presente su Win10/11.
